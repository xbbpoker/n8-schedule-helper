# N8 賽程小助手

免費的本機選賽工具：把 N8 賽事截圖丟進去，整理當天賽程、算同時開幾桌、結買前 1 分半響鈴。
它不連 N8 或任何打牌平台，只讀你自己的截圖；不需要登入。

- 安裝與使用教學：https://xbbpoker.github.io/n8-schedule-helper/
- Mac（macOS 13 以上）：https://github.com/xbbpoker/n8-schedule-helper/releases/latest/download/N8-Schedule-Mac-universal.zip
- Windows 10／11（測試版）：https://github.com/xbbpoker/n8-schedule-helper/releases/latest/download/N8-Schedule-Windows-x64-preview.zip

第一次打開會被系統擋一下（沒有付費的發行認證）：Mac 到「系統設定 → 隱私權與安全性 → 強制打開」；Windows 在藍色警告按「其他資訊 → 仍要執行」。
